# 웨딩 영수증 · Wedding Receipt

결혼 비용을 영수증처럼 관리하는 **무료 웹앱**이에요(앱 설치·심사 없이 링크로 열어요). 파일 하나(`index.html`)로 돌아가고,
서버·로그인·API 키가 필요 없어요. 데이터는 **각자 브라우저(localStorage)에만** 저장돼요.

## 기능
- 목표 총예산 / 항목별 예산 / 결제 내역 관리, 월별 현금흐름(카드는 청구월, 현금은 결제월)
- 카드 결제일·이용기간 마감일 설정 → 청구일 자동 계산, 할부 개월 분할
- 항목에 예정월을 넣으면 월별 리스트의 그 달에 표시
- **자유 입력 명령창** (규칙 기반, 비용 없음): 미리보기 → 적용 → 되돌리기(최근 10회)
  - "12/1 청첩장 15만원 카드 추가", "예복 3개월 할부로", "드레스 잔금 20만원 올려줘"
  - "청첩장 삭제", "신혼여행 11/26으로 옮겨줘", "목표 총예산 4천만원", "리본 장식 항목 추가 5만원"
- 엑셀용 CSV 내보내기, 모든 데이터 지우기

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 배포용 완성본 (이것만 올리면 됨) |
| `backend.js` | 브라우저 안 백엔드 소스 (저장·계산·명령 해석·되돌리기) |
| `build.py` | 화면 코드 + backend.js → index.html 빌드 (원본 앱 경로 필요) |
| `test_backend.js` | 백엔드 로직 테스트 (`node test_backend.js`) |

## 무료로 올리기 (정적 호스팅)
저장소 이름 추천: `wedding-receipt`
**GitHub Pages**
1. GitHub에 새 저장소 만들기 → `index.html` 업로드
2. Settings → Pages → Branch: `main` / `(root)` → Save
3. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 로 접속

**Cloudflare Pages**: 저장소 연결(또는 폴더 업로드) → 빌드 설정 없이 배포

## 개인정보 / 한계
- 데이터는 서버로 전송되지 않아요. 기기 간에 옮겨지지 않아요(필요하면 CSV로 내보내 보관).
- 브라우저 데이터를 지우면 사라져요. 시크릿 모드에서는 닫으면 사라져요.
- 폰트(Space Mono)는 Google Fonts에서 불러와요. 완전 오프라인이 필요하면 해당 `<link>`를 지우면 기본 모노스페이스 폰트로 표시돼요.
- 명령창은 규칙 기반이라 정해진 문장 형태만 알아들어요. 모르는 문장은 되물어요.
- 계산은 참고용이며 재무·세무 조언이 아니에요. 카드 청구일은 카드사 안내를 확인하세요.


## 꾸미기
- 설정 → 배경색: 프리셋 9가지 + 직접 고르기 (이 기기에만 저장)
- 오른쪽 아래 클립 달린 종이 조각: 눌러서 사진(앨범/파일)을 붙여 두고, 다시 누르면 크게 볼 수 있어요. 사진은 이 기기 브라우저에만 저장돼요.
- 예정월은 달력(월 선택)에서 고르고, 예정월이 없는 항목은 NOT SCHEDULED 목록에서 한 번에 고를 수 있어요.
